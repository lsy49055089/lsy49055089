TEAM PROJECT · 최우수상

CNN 모션인식 SoC 플랫폼

두 카메라의 관절 인식을 Zynq 5축 로봇팔의 실시간 추종과 동작 기록·재생으로 연결했습니다.

  • Zynq
  • AXI4-Lite
  • C
  • PWM
  • DDR / SD
기간
2026.09.09 — 2026.10.15
수행 형태
7인 팀
담당 역할
AXI4-Lite PWM IP, C 출력 제어·Record/Replay, 그리퍼 안정화, Unity 가상환경
주요 결과
5축 · 20 ms 제어 · 최우수상
01

PS–PL 출력 설계

PS의 C 코드는 목표 관절각·출력 모드·파일을 관리하고 PL의 PWM Core는 100 MHz에서 20 ms 주기 파형을 생성합니다. 5축 설정을 Shadow 레지스터에 기록한 뒤 UPDATE로 함께 적용합니다.

02

동작 기록·재생

보정·속도·가속도 제한을 거쳐 HAL 적용에 성공한 관절 명령을 20 ms마다 DDR에 기록하고 종료 후 SD에 보관합니다. 재생 전 데이터 검사와 첫 자세 ALIGN을 수행하며, 틱 누락·저장 실패 시 기록과 기존 파일을 보호합니다.

03

개인 구현 · 통합 디버깅

유효한 한쪽 카메라만으로 그리퍼를 판단하도록 바꿨습니다. 히스테리시스·새 관측 3회 확인·닫힘 후 1.5초 유지로 순간 잡음을 억제했습니다. 150 mm 좌표 도약 검사·재획득과 20 ms 궤적 제한을 연결해 갑작스러운 입력이 출력으로 바로 이어지지 않도록 했습니다.

04

검증

PWM RTL TB에서 축소 주기의 펄스 폭·주기·Shadow/UPDATE·Disable을 확인했습니다. PC 모의 C 회귀는 LEFT 16 / RIGHT 16 시나리오, PC 모니터는 131개 테스트를 통과했습니다. 이 결과와 별도로 최종 실물·Unity 통합 동작을 시연했습니다.

05

팀 역할과 수상

CNN RTL·UVM, 스테레오 3D 복원·관절각 계산은 다른 팀원 담당입니다. 칼만 필터·카메라별 검출 조건은 로봇팔팀 공동 작업입니다. 2026.10.15 최종 경진대회 최우수상 · 5개 팀 중 2위 · 전체 34명.
