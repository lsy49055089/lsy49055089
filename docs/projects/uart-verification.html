INDIVIDUAL · CLASS-BASED TB

UART · FIFO · Parity 검증

UART Loopback과 이중 FIFO의 데이터 순서를 비교하고 Parity 오류가 송신 경로로 전달되지 않는지 확인했습니다.

  • SystemVerilog
  • Mailbox
  • Virtual Interface
  • Assertion
기간
2026.05.12 — 2026.05.18
수행 형태
개인 프로젝트
담당 역할
UART/FIFO RTL, Class-based TB, Reference Queue, 오류 주입·차단 검증
주요 결과
16-entry FIFO · Odd Parity 오류 주입
01

구현

100 MHz·9,600 bps UART와 16x Oversampling, 8-bit 16-entry FIFO를 설계했습니다. Generator·Driver·Monitor·Scoreboard를 mailbox와 event로 연결한 class-based TB이며 UVM 라이브러리를 사용하지 않았습니다.

02

검증

FIFO Reset·Push/Pop·Random 조건을 Reference Queue와 비교했습니다. UART 프레임과 Parity 오류 주입을 확인하고 오류 데이터의 RX FIFO 입력·TX 전달이 차단되는지 검사했습니다.

03

문제 해결

중앙 Sampling 기준으로 Start-bit 수신 시점을 맞춰 한 비트 밀림을 수정했습니다. RX FIFO Push 조건에 Parity 오류 차단을 추가해 오류 데이터의 재전송을 막았습니다.
