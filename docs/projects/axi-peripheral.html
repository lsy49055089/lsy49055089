MicroBlaze AXI4-Lite IP

5종 Custom IP와 C MMIO 드라이버를 설계하고 두 대의 FPGA 보드 통신까지 연결했습니다.

  • Verilog
  • MicroBlaze
  • AXI4-Lite
  • Vitis C
기간
2026.06.22 — 2026.06.30
수행 형태
개인 프로젝트
담당 역할
GPIO·Timer·UART·SPI·I2C LCD IP, Register Map, Vitis C 제어, 보드 통합
주요 결과
IP 5종 · SPI 32/32 · I2C 30/30 PASS
01

설계

MicroBlaze와 AXI Interconnect에 GPIO·Timer·UART·SPI·I2C LCD Custom IP를 연결했습니다. 각 IP의 Register Map과 C MMIO 드라이버를 구성하고 두 Basys3 보드의 UART·SPI 송수신을 통합했습니다.

02

문제 해결

Sticky DONE의 이전 완료 상태가 다음 요청에 섞이지 않도록 상태 확인·해제·시작 순서를 정리했습니다. SPI 첫 MISO 비트 출력 시점을 조정하고 UART 핀 충돌을 해결했습니다.

03

검증

AXI-SPI UVM 32/32, I2C 통신 UVM 30/30 PASS와 실제 보드 통신을 확인했습니다. 이 시험은 별도의 SPI·I2C 단독 UVM 10,000건 확장 회귀와 구분합니다.

04

구현 범위

Timer IP는 설계 범위에 포함됩니다. 최종 Vitis 데모의 카운트 동작은 소프트웨어 변수로 처리했습니다.
