병렬 결정트리 RTL

현재 노드와 좌우 자식 노드를 함께 계산해, 한 입력 벡터의 트리 탐색 시간을 줄인 하드웨어입니다.

  • Verilog
  • FSM / Datapath
  • Vivado
  • Icarus Verilog
기간
2025.07 — 2025.11
수행 형태
학부 연구
담당 역할
3-UN Datapath·FSM 설계, 결과 동등성 검증, 제1저자 논문 작성·발표
주요 결과
논문 실험 평균 1.37× · RTL 회귀 37/37
01

설계 판단

부모의 분기 결과가 나오기 전, 좌우 자식 후보를 미리 계산했습니다. UN1은 현재 노드, UN2·UN3은 자식 노드를 담당하고 Logic이 분기 결과에 맞는 계산값을 선택합니다. 선택된 다음 노드를 주소 메모리에 피드백해 탐색을 이어갑니다.

02

제어 흐름 개선

동일한 데이터패스에서 6-state 제어를 4-state로 통합했습니다. 다음 입력과 대기 제어를 기존 상태에 묶어 불필요한 상태 전환을 줄였습니다.

03

검증 결과

Icarus Verilog에서 동일한 입력 벡터 37개를 사용했습니다. 6-state와 4-state의 분류 결과가 모두 일치했고, 37개 벡터의 전체 완료 사이클은 293 → 255로 줄었습니다. DONE-state assertion과 기대 클래스 비교를 자동화했습니다.

04

논문 성능

2025 학술대회 논문은 Artix-7·Vivado에서 순차 UN1과 병렬 UN3를 비교해 평균 1.37배 성능 향상을 보고했습니다. 위 293 → 255 cycles는 동일 데이터패스의 FSM 회귀 결과로, 서로 다른 비교입니다.

05
