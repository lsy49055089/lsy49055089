TEAM PROJECT · VIDEO RTL

FPGA 영상 좌표 처리 · 지휘 게임

OV7670 영상의 빨강·초록 표식 좌표를 계산하고 지휘 게임과 PC MAESTRO UI에 전달했습니다.

  • SystemVerilog
  • OV7670
  • Basys3
  • UART
  • Python
기간
2026.08.31 — 2026.09.07
수행 형태
7인 팀
담당 역할
xy_detection·song_decoder RTL/TB, 군집화·프레임 동기화, FPGA–PC UI 연동
주요 결과
320×240 입력 · RED/GREEN X·Y 40-bit
01

영상 좌표 처리

RED/GREEN 검출 픽셀에서 MIN/MAX를 누적해 Bounding Box 중심을 계산했습니다. 이웃 픽셀·Bounding Box·최소 픽셀 조건으로 잡음을 걸러내고 미검출 좌표를 구분했습니다. RED/GREEN 각각의 X·Y, 총 4개 좌표값을 40-bit로 전달합니다.

02

프레임 지연 해결

연산식뿐 아니라 프레임 종료, 좌표 레지스터 확정, 후단의 데이터 사용 시점을 분리해 추적했습니다. 좌표 확정 뒤 다음 클록에 Valid를 전달하도록 맞추고 QVGA 320×240와 PC 표시 640×480의 좌표 대응을 정리했습니다.

03

검증과 연동

xy_detection TB에서 좌표 출력·미검출·Ready/Valid 조건을, song_decoder TB에서 곡 선택·BPM을 확인했습니다. UART로 전달한 좌표를 PC 검출 영상에 표시하고 MAESTRO UI·MIDI 재생까지 연동했습니다.

04

팀 내 역할

개인 담당은 좌표 처리·곡 디코더 RTL/TB와 PC 연동입니다. 게임 로직과 팀 단위 UVM 통합 검증은 팀 공동 개발 범위입니다.
