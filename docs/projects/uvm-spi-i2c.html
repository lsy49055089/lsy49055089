01

검증 환경

Transaction·Sequence·Driver·Monitor·Agent·Environment·Test를 구성하고 Analysis Port로 Scoreboard와 Coverage를 연결했습니다. Config DB로 virtual interface를 전달하고 Phase·Objection으로 시뮬레이션 종료를 관리했습니다.

02

SPI 결과

SPI Mode 0 · Directed 8 + Random 9,992 = 10,000 트랜잭션. Scoreboard 10,000 PASS / 0 FAIL. 데이터와 응답 타이밍을 기대값과 비교했습니다.

03

I2C 결과

정상 주소·잘못된 주소·Read/Write·ACK/NACK 조건을 포함한 4개 동작을 각 2,500회 수행했습니다. 10,000 트랜잭션에서 17,500개 Scoreboard 검사 PASS / 0 FAIL입니다. 트랜잭션 수와 검사 수는 서로 다릅니다.

04

Functional Coverage

I2C Functional Coverage 83.33%. 정의한 6개 Coverpoint는 100%, 3개 Cross 항목은 각각 50%입니다. 미충족 Cross가 있어 전체 조건을 모두 시험한 결과로 해석하지 않습니다.
