01

담당 구현

DHT11 단일 데이터선의 1 µs 타이밍과 40-bit 데이터 수신 FSM, Checksum을 구현했습니다. 센서 단위 TB와 최종 top_4module 통합 TB를 작성하고 공용 FND 통합에 참여했습니다.

02

검증

파형과 Basys3에서 온습도 모드·통합 동작을 확인했습니다. 공개 자료의 전체 독립 합성에는 원본 UART/FIFO 하위 RTL과 XDC가 추가로 필요합니다.
