DQN 물류창고 배치 시뮬레이션

물품 속성과 2층 창고의 적재 상태를 받아 빈 슬롯을 선택하는 강화학습 환경을 구현했습니다.

  • NumPy
  • DQN
  • Matplotlib
기간
2024.12.02 — 2024.12.20
수행 형태
개인 프로젝트
담당 역할

주요 결과
146개 관측값 · 33개 행동 후보
01

설계

2층 10×7 격자와 무게별 층 선택을 구성하고 점유 슬롯을 행동 마스크로 제외했습니다. NumPy 기반 146 → 64 → 64 → 33 네트워크에 경험 재생·타깃 네트워크를 적용했습니다.

02

확인 범위

단계별 보상과 100·200·300회 학습 시점의 배치를 시각화했습니다. 샘플 데이터의 정책 비교와 300회 학습 화면은 별도 실행이며, 자동 시험 7개로 환경·전처리·가중치·출력 생성을 점검했습니다.
